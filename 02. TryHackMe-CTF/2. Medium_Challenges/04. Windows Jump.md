``'guest%'`` is a compact way to tell smbclient:
````
Username = guest
Password = empty
````
The format of it: `-U 'USERNAME%PASSWORD'`

The ``%`` separates the username from the password.


| Command                  | Meaning                                          |
| ------------------------ | ------------------------------------------------ |
| `-U guest`               | Username is `guest`; SMB may prompt for password |
| `-U 'guest%'`            | Username is `guest`; use an empty password       |
| `-U 'guest%Password123'` | Username `guest`, password `Password123`         |


Then connect it:

### Key Takeaway:
````
A useful mindset is:

What runs with higher privileges?
        ↓
What does it execute/use?
        ↓
Can my current account modify or influence that?
        ↓
Would that give me another account or SYSTEM?
````
| Vulnerability / technique          | What you identify first                                          | How to check                                                             | What makes it actually vulnerable                                                         |
| ---------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------- |
| **Guest SMB**                      | SMB allows anonymous/guest access                                | `smbclient -L //TARGET -U 'guest%'`                                      | Guest can access useful/sensitive files, credentials, or writable shares                  |
| **Exposed credentials**            | Passwords stored in files, registry, history, application config | `reg query ...`, `cmdkey /list`, PowerShell history, search config files | Recovered credential belongs to another useful account                                    |
| **Writable service executable**    | Service executable path + service account                        | `sc.exe qc SERVICE` + `icacls EXE`                                       | Service runs as privileged user **and** low-privileged user can modify/replace EXE        |
| **Insecure service configuration** | Who can change the service itself                                | `accesschk.exe -qlc SERVICE`                                             | Low-privileged user can modify service configuration and service runs privileged          |
| **Unquoted service path**          | Unquoted path containing spaces                                  | `sc.exe qc SERVICE`                                                      | A path component before the real executable is writable                                   |
| **Scheduled task**                 | What command runs and under which account                        | `schtasks /query /fo LIST /v`                                            | Task runs privileged and the script/binary or its directory is writable/influenceable     |
| **PATH hijacking**                 | Privileged program calls a command without absolute path         | Check script + `echo %PATH%` / service environment                       | Higher-privileged PATH contains a directory you can write to                              |
| **SeBackupPrivilege**              | Special Windows privilege assigned to your account               | `whoami /priv`                                                           | Protected data can be accessed through backup semantics                                   |
| **SeTakeOwnershipPrivilege**       | Ownership privilege                                              | `whoami /priv`                                                           | You can take ownership of a valuable protected object and then alter its permissions      |
| **SeImpersonatePrivilege**         | Impersonation privilege                                          | `whoami /priv`                                                           | A process with this privilege can potentially be abused to obtain a more privileged token |
| **Vulnerable software**            | Installed software + exact version                               | `Get-CimInstance Win32_Product`, software inventory, `systeminfo`        | Version matches a known exploitable vulnerability under the current conditions            |
| **Weak file permissions**          | Who owns a file and who can write it                             | `icacls FILE`, `Get-Acl`                                                 | Low user can modify something executed by a higher-privileged process                     |
