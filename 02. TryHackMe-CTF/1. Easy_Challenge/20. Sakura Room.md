## Task 1: Introduction

<img width="325" height="374" alt="image" src="https://github.com/user-attachments/assets/88f6eaf3-bb58-40c3-950e-dd6f85884980" />


### Background

**OSINT (Open-Source Intelligence)** is the process of collecting and analyzing publicly available information.

This room teaches us how to investigate a simulated cybercriminal by finding usernames, social media accounts, digital footprints, and other online information.

There are two types of OSINT:

- **Passive OSINT:** Collecting information without directly interacting with the target.
- **Active OSINT:** Collecting information by directly interacting with the target.

**Note:** This room allows only passive OSINT. Do not contact account owners, attempt password resets, or hack accounts.

## Task 3: RECONNAISSANCE

### Background

The attacker made an **OPSEC (Operational Security) mistake** by using the same username across multiple social media platforms.

This allows investigators to discover other accounts and gather additional information about the attacker.

#### **Some tools**

| Tool           | Purpose                                     |
| -------------- | ------------------------------------------- |
| Sherlock       | Find accounts across social media platforms |
| Maigret        | Collect information from usernames          |
| Namechk        | Check usernames across websites             |
| Google Dorking | Search for specific usernames               |

---


### Instructions

**Username Enumeration** is an OSINT technique used to discover accounts across different online platforms using the same username.

#### **Investigation methods**

- **Search engines:** Search for the exact username using Google.
- **OSINT tools:** Use Sherlock, Maigret, or Namechk.
- **Manual investigation:** Check individual websites.
- **Verification:** Confirm that the accounts belong to the same person.

#### **Common problems**

| Term           | Meaning                                                       |
| -------------- | ------------------------------------------------------------- |
| False Positive | The tool finds an account that does not belong to the target. |
| False Negative | The tool fails to find an account that actually exists.       |

**Main goal:** Use the username `SakuraSnowAngelAiko` to discover other accounts and collect additional information within the lab.
